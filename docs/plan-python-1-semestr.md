### Неделя 1 · урок 1. Выведи объявление на табло колледжа

**Навык:** print(), строки и порядок команд · **время:** 10 мин · файл `content/python/02-tablo-pervaya-programma.json`

**История.** В холле колледжа висит табло. Дежурный пишет для него программу: на табло должно появиться «Пары начинаются в 8:30» и «Столовая работает до 16:00». Но программа падает с ошибкой. Разберёмся, как Python выводит текст.

**Теория (на неё опирается тьютор).** print() выводит на экран то, что стоит в скобках. Текст (строку) пишут в кавычках: "..." или '...'. Без кавычек Python пытается прочитать текст как код: одно слово он считает именем переменной и, если такой переменной нет, останавливается с ошибкой NameError; несколько слов подряд — это уже ошибка SyntaxError, и программа не запустится вовсе. Числа можно писать без кавычек: print(2026). Регистр важен: Print и print — разные имена, работает только print. Команды выполняются сверху вниз, каждый print начинает новую строку. Если в print несколько значений через запятую, они выводятся в одну строку через пробел: print("Группа", "ИС-21") → Группа ИС-21. Строка, которая начинается с #, — комментарий: Python её пропускает. Вывод: текст — в кавычках, команды — по порядку, одна команда print — одна строка на экране.

**Шаг 1. Какой код выведет текст?**

Нужно, чтобы на табло появилось: Пары начинаются в 8:30. Какая команда это сделает?

- `print(Пары начинаются в 8:30)`
- `print("Пары начинаются в 8:30")` ✔
- `Print("Пары начинаются в 8:30")`

Подсказки: «Python должен понять, где начинается и заканчивается текст.» → «Чем в Python отмечают текст — кавычками или скобками?» → «Пример: print("Сегодня суббота") выводит Сегодня суббота.»

Объясни проще: «Кавычки для Python — как рамка вокруг объявления: всё, что внутри, печатается как есть.»

Разбор ошибок:
- вариант «print(Пары начинаются в 8:30)»: Без кавычек Python читает текст как код. Несколько слов подряд для него — бессмыслица: ошибка SyntaxError, программа даже не запустится.
- вариант «Print("Пары начинаются в 8:30")»: Python различает большие и маленькие буквы: команда называется print, а Print — неизвестное имя.

**Шаг 2. Что появится на табло?**

Что выведет этот код?

```python
print("Группа", "ИС-21")
print("Пара", 3)
```

- Две строки: «Группа ИС-21» и «Пара 3» ✔
- Одна строка: «ГруппаИС-21Пара3»
- Одна строка: «Группа, ИС-21, Пара, 3»

Подсказки: «Каждый print начинает новую строку.» → «Что print ставит между значениями, перечисленными через запятую?» → «Пример: print("Аудитория", 214) выводит Аудитория 214 — с пробелом.»

Объясни проще: «Запятая в print — это пробел на экране, а новый print — новая строчка на табло.»

Разбор ошибок:
- вариант «Одна строка: «ГруппаИС-21Пара3»»: Значения через запятую print разделяет пробелом, а каждый новый print — это новая строка.
- вариант «Одна строка: «Группа, ИС-21, Пара, 3»»: Запятые в коде разделяют значения, но на экран они не выводятся — вместо них пробел.

**Шаг 3. Сколько строк на табло?**

Сколько строк появится на табло после запуска этого кода?

Объясни проще: «Решётка # — как зачёркнутая строчка в черновике: её видно, но её не читают вслух.»

Разбор ошибок:
- ответ 4: Строка с # — комментарий. Python её пропускает, поэтому «Пары отменены» на табло не появится.

*Напиши код сам:* Напиши программу, которая выводит две строки: «Пары начинаются в 8:30» и «Столовая работает до 16:00».

**Шаг 4. Объявление о звонке** · *самостоятельно, без подсказок*

На табло сначала должно появиться «Звонок через 5 минут», а под ним — «Не опаздывайте». Какая программа сделает это правильно?

- `print("Звонок через 5 минут", "Не опаздывайте")`

### Неделя 4 · урок 8. Почему за 95 баллов — «удовлетворительно»?

Вторая часть: Условно: повышенная — 2 единицы, обычная — 1, без стипендии — 0. Сколько единиц получит студент со средним баллом ровно 4.5? — **2** ✔

Решение для преподавателя: Начинаем с самого высокого порога: avg >= 4.5, потом avg >= 3.5. Граница «от 4.5» включена — нужен >=, а не >. Средний балл ровно 4.5 даёт повышенную стипендию — 2 единицы.

- Вариант 2: Абонемент в спортзал колледжа: от 20 занятий — скидка 40%, от 10 занятий — 20%, меньше — без скидки. Какое начало цепочки считает скидку правильно? → **if visits >= 20: 40% … elif visits >= 10: 20% …**; Какая скидка в процентах будет ровно при 10 занятиях? — **20**
- Вариант 3: Кофейня у колледжа: от 10 покупок — 3 бонуса, от 5 покупок — 1 бонус, меньше — без бонусов. Какое начало цепочки считает бонусы правильно? → **if buys >= 10: 3 … elif buys >= 5: 1 …**; Сколько бонусов получит покупатель ровно за 10 покупок? — **3**
